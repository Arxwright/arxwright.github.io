# Arxwright brand

`bun install && bun run build` regenerates everything in `out/` (needs `rsvg-convert`). Outputs are committed.

- **Mark**: the crown of an arch, three voussoirs with the keystone proud, a wedge-headed club
  hammer cut from the keystone. *Arx* = citadel, *wright* = builder. The hammer head's ends run
  parallel to the keystone's sides; keep that if the geometry changes.
- **Colour**: verdigris. Light `#2e5b50` on `#f2f4f1`, dark `#86b8aa` on `#151d1b`, ink
  `#1f2a27` / `#dfe7e4`. Both marks clear 7:1 on their grounds, so they can set text too.
- **Wordmark**: Tenor Sans capitals, tracked 0.14em, outlined into the SVGs (`fonts/`, OFL).
- **Lockup**: mark at 1.3× cap height, centred on the capitals, 0.45em gap.
- The favicon follows the browser theme; `icon-tile.svg` and the PNG app icons are opaque.
- Arxwright stays quieter than its products: one colour, no accent.
